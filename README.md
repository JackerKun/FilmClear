## 下载与运行

在 [GitHub Releases](https://github.com/JackerKun/FilmClear/releases/latest) 选择与系统匹配的归档。新版本的发布说明会先上线，构建完成后，同一页会附上各平台归档和 `SHA256SUMS.txt` 校验文件。

| 系统 | 下载文件 | 解压后启动 |
| --- | --- | --- |
| macOS Apple Silicon | `FilmClear-macOS-arm64.zip` | 打开 `FilmClear.app` |
| macOS Intel | `FilmClear-macOS-x64.zip` | 打开 `FilmClear.app` |
| Windows x64 | `FilmClear-Windows-x64.zip` | 进入 `FilmClear` 文件夹，打开 `FilmClear.exe` |
| Linux x64 | `FilmClear-Linux-x64.tar.gz` | 在解压目录运行 `./FilmClear/FilmClear` |

Windows 和 Linux 请保留整个解压目录。macOS 构建使用临时签名，跨机器下载时系统可能要求确认。Linux 需要图形桌面及其 Qt 系统库。

## 快速上手

1. **导入照片**。点左侧的添加照片或文件夹图标，也可把照片直接拖入窗口。支持 JPEG、PNG、TIFF、WebP、BMP。右键照片可打开原文件所在位置或从列表移除。清空列表需确认，重新导入可继续使用已有修复记录。
2. **扫描缺陷**。默认「主体优先」关注人脸和平坦背景，在山林等复杂纹理中更保守。RGB 整图扫描会跳过识别出的黑色片框和齿孔区域。「快速预览」在缩放图上查找候选，较细的划痕和毛絮会以更高分辨率复查。可切换到「原图精查」或「全画面」。
3. **核对候选**。候选默认勾选并显示标记。悬停列表可查看局部，点击可在原图定位。拖框「补查」或在瑕疵附近「描画」，程序会在原图像素上寻找实际缺陷轮廓。
4. **修复与对比**。可框选勾选、忽略或修复，按住 Shift 可叠加多个勾选框。修复和忽略可撤销。前后对比支持滑动分割、左右并排、上下排列，双画面同步缩放和平移。原片一侧保留待处理和已修复位置的缺陷圈，按 `M` 切换显示。
5. **导出**。使用原图像素应用修复和裁切，可跟随原格式或统一为 JPEG、PNG、TIFF。PNG 和 TIFF 支持 16 位输出。批量导出可选择照片、查看进度和取消剩余任务。

画布底部的「手动修图」可以直接编辑像素。使用「仿制图章」时，按住 `Option`（Windows / Linux 为 `Alt`）点击照片指定取样点，再到目标区域点击或拖画。「污点修复」可点击灰点或沿毛絮、划痕拖画。默认自动模式下，笔迹与细长缺陷高度吻合时会沿实际轮廓修复。圆形笔尖随半径和缩放变化，每笔编辑都可以单独撤销，并随工作区保存。

点击画布顶部的小图标或分隔线中间的箭头，可独立收起照片栏和缺陷检查栏。两侧栏的宽度和折叠状态会随工作区一起恢复。

工作区会在本机自动保存照片列表、候选、勾选、忽略、修复、撤销记录和视图位置。右键「重置照片」可清除该照片的扫描和编辑记录，从原片重新开始。原片暂时离线时也可以清除缓存编辑，等原片重新可用后再扫描。

## 裁切与旋转

点击画布下方的「裁切」或按 `C`。程序会识别 135 和 120 扫描的有效画面，并参考可见的胶片齿孔建议矩形裁切范围。拖动任意边线或四角可改变大小，拖动框内可移动位置。旋转默认是 0°，可手动微调扫描倾斜，用网格校平，再切到「结果预览」。导出使用矩形裁切和纯旋转。旧工作区的四角裁切会按矩形读取。

对于贴着扫描边缘的细黑边，程序会检查原始边缘像素。单侧识别也会给出裁切建议，证据不足的边保留原范围。批量处理时，这些照片会列入「需要核对」。

「画幅」可选自由比例、135、XPan、6×4.5、6×6、6×7、6×8、6×9、6×12 和 6×17。预设随横竖构图锁定裁切比例，具体相机片门和扫描留边可能有差异，可用自由比例微调。

默认保留边框为 **0%**。设为 **2%** 时，每边相对有效画面的宽或高多留 2%，以扫描原图能提供的边框为限。应用后可撤销。右击照片选择「取消裁切」，或在裁切窗口点击同名按钮，可恢复完整画面和原始角度，并保留修复记录。批量裁切窗口中的「取消所选裁切」可对勾选的照片执行同一操作。设置随照片保存。前后对比使用相同取景，批量导出时应用各自的裁切，选择「复制原文件」仍会输出完整的原始文件。

整卷处理时，点击「批量裁切」。

1. 勾选照片，统一设置留边比例和初始画幅，再点「识别片框」。
2. 四边齐全的自动结果默认勾选。双击「需要核对」中的照片，可用「上一张」「下一张」或 `Page Up` / `Page Down` 连续检查。点击「确认并下一张」会确认当前照片，返回列表会保留已确认的结果和未确认的草稿。
3. 点击「应用所选裁切」才会保存勾选的结果。只想应用手动确认的照片时，先点「仅勾选手动确认」。应用或取消裁切都可逐张撤销。

右击画布，在「画布背景」中选择预设或自定义颜色。设置会记住，也会用于并排对比和裁切预览。

## 批量扫描与审片

- **筛选照片**。左侧可搜索文件名，并切换「待扫」「候选」「修复」。照片栏显示当前可见数量和已扫描数量，上一张和下一张会在筛选结果中移动。
- **批量扫描**。在右侧或文件菜单选择要扫描的照片。完成的照片会逐张保存。可以停止扫描，或从文件菜单重试失败项。
- **快速核对**。按 `J` / `K` 跳到下一处 / 上一处候选并保持倍率。快速预览候选可按 `R` 或点「原图核对」，用原始像素重新提取轮廓。
- **显尘与三联预览**。点「显尘」并调整对比度可查找漏检。打开「三联预览」可同时查看原片、蒙版和试修结果。这些视图只用于检查。
- **同卷重复候选**。批量扫描同一卷后，从「编辑」打开同卷重复候选。应用会提示至少三张照片中位置和大小相近的斑点。并排确认后可逐组修复或忽略，支持逐张撤销。
- **保颗粒与保色**。自动修复对小灰点使用快速填补，对较大蒙版参考邻域颗粒。导出对话框显示格式、位深和 ICC 情况。修复输出保留兼容的 RGB ICC 与适用元数据，PNG 和 TIFF 保持 16 位像素。
- **导出对照页**。在导出窗口勾选「同时生成前后对照页」，即可保存一份可离线打开的 HTML。支持左右并排、上下排列、滑动分割、同步缩放和平移。青色标记代表已修复，琥珀色代表待处理；可隐藏标记，或点击缺陷切换到该处的前后局部。导出后可从状态栏打开对照页或输出目录。

## 红外扫描

- VueScan 导出时可选择 **Raw file**、**64 bit RGBI**、**Raw output with = Scan**。FilmClear 会识别 TIFF 的内嵌红外通道。
- 同目录的 `照片名_IR.tif` 或 `照片名_infrared.tiff` 可自动关联。也可从文件菜单指定已对齐的红外图，或手动将 TIFF 第四通道作为红外。
- 用右侧「RGB / 红外 / 叠加」检查对齐，候选提示会标明检测来源。红外信号不足时可切到「仅 RGB」。导出时选择「复制原文件」可保留内嵌红外通道及原文件元数据。

## 从源码运行与打包

需要 Python 3.10 或更新版本。macOS 和 Linux 可在项目根目录运行：

```bash
./start.sh
./start.sh --test -v
```

Windows 可在命令提示符中运行：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

个人扫描样本放在 `demo/`。干净的仓库检出会运行合成样本测试，并跳过依赖本地扫描照片的用例。

| 本地打包 | 命令 | 输出 |
| --- | --- | --- |
| macOS | `./build.sh` | `dist/macos/FilmClear.app` |
| Windows | `build.bat` | `dist/windows/FilmClear/FilmClear.exe` |
| Linux | `./build.sh` | `dist/linux/FilmClear/FilmClear` |

打包脚本使用独立的 `.venv-build`，并将运行依赖、图标和 YuNet 权重放入产物。首次建立打包环境时，可通过 `FILMCLEAR_PYTHON` 指定 Python 可执行文件。GitHub Actions 在推送 `v*` 标签后构建各平台归档、检查程序启动，并发布下载和校验文件。

## 本地样片评测

```bash
.venv/bin/python -m tools.benchmark --repeats 3
```

评测输出候选数、已标注缺陷的漏检数、胶片齿孔带内候选数及扫描耗时 P50/P95。可以用 `--review` 提供 JSON，格式为 `{"照片文件名":{"全图":{"rejected_points":[[x,y]]}}}`，用于统计与人工驳回标注匹配的候选。未复核的候选不计作误报。

可用 `--lama-model /path/to/big-lama.pt --repair-previews /path/to/output` 比较较大蒙版下的 Navier–Stokes、保颗粒和 LaMa，并输出局部对照图。LaMa 评测需要当前虚拟环境额外安装 PyTorch，权重使用 [IOPaint 的参考发布](https://github.com/Sanster/IOPaint/blob/main/iopaint/model/lama.py)。

## 模型与素材

「主体优先」使用 YuNet 定位人脸，缺陷轮廓由原图检测生成。模型权重来自 [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)，随附 [MIT 许可证](models/YuNet-LICENSE.txt)。应用图标的矢量源文件位于 [assets/filmclear.svg](assets/filmclear.svg)。
