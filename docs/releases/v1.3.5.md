FilmClear 1.3.5 补齐了系统兼容性说明和中文发布说明。请按操作系统版本和处理器架构选择下载包。

- **Windows x64**：支持 Windows 10 1809（内部版本 17763）至 22H2，含 LTSC 2019 和 LTSC 2021，以及 Windows 11。Windows 10 2016 LTSB（1607）低于最低要求。
- **macOS**：支持 macOS Sonoma 14.4 起、Sequoia 15 和 Tahoe 26。Apple Silicon 选择 arm64，Intel Mac 选择 x64。
- **Linux x64**：适用于 Ubuntu 22.04 LTS 和 24.04 LTS 桌面版。

从 v1.3.3 或更早版本升级时，也会获得 v1.3.4 的两项修复：启动时在独立进程检查更新，GitHub 无法访问时仍可继续使用主窗口；「主体优先」的人脸模型不可用时，仍会按画面纹理离线扫描灰尘、毛絮和划痕。

Windows 下载后请完整解压，再打开 `FilmClear.exe`。各平台下载包和 `SHA256SUMS.txt` 都在本页的 Assets 中。
