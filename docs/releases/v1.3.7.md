FilmClear 1.3.7 增加毛絮自训练和模型管理，并改进划痕、毛絮候选的核对方式。

- **本机标注与训练。** 从「工具 → 毛絮学习 → 标注与训练」进入，沿毛絮或划痕描画，也可框选查找实际轮廓。将候选保存为「真实缺陷」或「画面线条」，翻页核对后即可训练，并将结果导出为 JSON。
- **模型管理与补检。** 支持导入模型、翻页预览缺陷轮廓、启用或停用多个模型。删除库内模型时保留原始 JSON 和标注。启用后选择「仅 RGB」重新扫描，新增的「模型补检」候选默认未勾选，核对后可手动修复。
- **保护画面细节。** RGB 扫描增强了五官与场景线的保护，并减少胶片齿孔和片框边缘的误检。画布缺陷标记可在轮廓和圆圈之间切换。
- **随附模型。** 软件包附带由模拟样片训练的毛絮模型，发布附件也提供可单独导入的 `FilmClear-Fiber-Model.json`。识别效果随样片纹理、对比度和角度变化。

发布附件包含 Windows x64、macOS Apple Silicon、macOS Intel、Linux x64 和 SHA-256 校验文件。Windows 用户请完整解压后运行 `FilmClear.exe`。
