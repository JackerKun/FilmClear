FilmClear 1.3.6 增加 HEIC 导入和 HDR 导出，并改进了批量导出。

- **HEIC 和 HDR**。可导入 HEIC / HEIF，把 16 位 sRGB TIFF 或 PNG 导出为 Ultra HDR JPEG 或 10 位 PQ HEIC，也可重新导出或互转受支持的 HDR 文件。
- **批量导出**。更大的导出窗口显示缩略图，支持整行点击、Shift 连选和全选。移除照片或清空列表后，导出窗口只显示当前导入的照片。重新导入时仍可恢复修复记录。
- **TIFF 修复**。修复部分 16 位 TIFF 因 DPI 字段类型不兼容而无法导出的问题，导出保留位深、DPI 和 ICC 色彩配置。

Windows 用户请完整解压后运行 `FilmClear.exe`。发布附件包含 Windows x64、macOS Apple Silicon、macOS Intel、Linux x64 和 SHA-256 校验文件。
