# 毛絮自训练与模型管理

适用于带有「工具 → 毛絮学习」菜单的 FilmClear 版本。标注、训练与模型识别均在本机进行。

## 标注一张照片

1. 在工作台选中照片，打开「工具 → 毛絮学习 → 标注与训练」。在「照片标注」页选择「沿毛絮描画」，顺着缺陷拖动鼠标，松开后会沿笔迹查找原图中的轮廓并勾选找到的候选。「框选查找」适合先圈出缺陷附近的区域。按住空格并用左键拖动可平移，滚动鼠标滚轮可缩放。
2. 点击右侧列表中的候选可定位并放大查看。核对后，将划痕或毛絮「保存为真实缺陷」，将窗框、电线等场景结构「保存为画面线条」。列表有焦点时，`1`、`2`、`3` 分别标记当前一处为真实缺陷、画面线条或跳过。
3. 用「上一张」「下一张」连续标注。照片默认按所在目录分组，同一卷也可填写相同的「胶卷分组」。训练读取已保存的标签，待标注候选和未保存的勾选不进入训练。

## 核对样本与训练

1. 切到「全部标注与训练」，翻页核对所有照片已保存的样本。只有特征参数的旧样本会标为「示意」。工作台未选中照片时，「标注与训练」也可直接打开样本与训练页。
2. 至少保存一处通过描画或框选找到的真实缺陷，或分别保存真实缺陷和画面线条各一处，即可点击「训练模型」。手动找到的真实缺陷可用于生成补检模板。两类样本都有时，程序还会训练候选分类，用于降低部分场景线误选。
3. 训练完成后，到「模型管理」找到新增模型并启用。需要交换或备份模型时，回到训练页点击「导出训练结果…」，可保存最近一次训练的 JSON。

## 管理模型与验证效果

- 在「工具 → 毛絮学习 → 模型管理」中选中模型，可查看来源和缺陷轮廓，并用「上一页」「下一页」翻看。没有保存轮廓的模板会显示示意图。
- 点击「导入 JSON…」添加已有模型。按 Windows / Linux 的 Ctrl 或 macOS 的 Command 可多选，用「启用所选」或「停用所选」切换状态。多个已启用模型会共同参与扫描。操作后可继续查看，点击「关闭」回到工作台。
- v1.3.7 发布包含一份用模拟样片训练的「随附模型」。也可在该版本的 Release 下载 `FilmClear-Fiber-Model.json`，在需要时导入。
- 选择「删除所选…」并确认后，软件会移除选中的本机模型库条目。原始 JSON 和已保存的照片标注会保留。
- 在工作台将检测来源设为「仅 RGB」，点击「扫描缺陷」重新扫描全图。选「全部候选」或「划痕 / 毛絮」可看到默认未勾选的「模型补检」候选。先看局部预览，确认是缺陷后再勾选修复。

可以用 [HDR 窗景样片](../demo/HDR-window-16bit.tif) 练习。放大左下窗格上缘的浅色斜划痕，沿线描画并保存，然后训练、启用和复扫。模型可以找出形状、宽度和局部对比度相近的候选。背景纹理、角度和亮度变化会影响结果，尤其需要核对枝叶、栏杆等结构较多的区域。

## 模型文件与本机标注

| 文件 | 内容与用途 |
| --- | --- |
| 导出的 `.json` | 可导入 FilmClear 的模型参数与可用轮廓，适合分享。文件不包含原照片或标注库。 |
| `filmclear_fiber_learning.sqlite3` | 保存本机标注和模型库。与 `filmclear_config.json` 位于同一配置目录，从源码运行时默认在项目根目录。需要备份完整标注时，先关闭 FilmClear，再备份此数据库。 |
| `filmclear_workspace.sqlite3` | 保存照片列表和工作区编辑记录。 |
